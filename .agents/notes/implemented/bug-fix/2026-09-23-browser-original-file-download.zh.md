# Agent Note: 浏览器下载保持当前源文件

Status: implemented

[English](2026-09-23-browser-original-file-download.md) | 中文

## 问题

远程浏览器不能通过 Host 的默认桌面应用保存生成文件。预览内容不能替代原始文档：文本可能经过分页，Office 预览则包含转换后的 PDF 字节。

## 决策

[文档预览](../../../../packages/client/ui-sidebar-documentpreview/README.zh.md)为其所寻址的 Session 文件提供显式浏览器下载。它通过现有、经过鉴权的 `workspaceFiles.readAll` 方法读取当前原始字节，保留文件系统策略和已配置的完整文件上限。它将这些字节作为带有原始基本文件名的附件交给浏览器，不调用 Host 应用，也不发布新的文件路由。

这为[工作区源文件决策](../feature/2026-09-08-present-workspace-source-files.zh.md)补充了显式的浏览器保存操作；不含内容的交付声明、原生打开，以及不保留交付快照的规则均保持不变。下载既不修改文件，也不增加会话事件或模型输入。

每个 tab 持有自己的请求，最多保留一个对象 URL。重复的待完成操作共享同一次读取。关闭 tab 会取消请求并释放其 URL；插件释放还会等待此前已关闭 tab 的被取消读取完成。迟到的结果不能启动下载。状态表示文件已交给浏览器，而不表示已成功保存到磁盘。

## 考虑过的替代方案

**下载已显示的内容**可能静默保存不完整的文本前缀或转换后的 Office 预览。读取原文件可保持每个字节，不受渲染器可用性和预览状态影响。

**专用下载端点**会在同一个有界文件读取器之上增加传输操作。现有完整字节方法已经负责鉴权、Session 路径解析、普通文件检查和大小拒绝；回退到原生打开还依赖服务器部署中不可用的桌面。

**持久化不可变交付副本**会引入存储和保留策略。本改动保持现有的当前源文件语义，不在删除后保留文件，也不冻结已显示的版本。

## 影响

完整下载会在 Host 和浏览器中缓存有界的源字节。超过 `maxFileBytes` 的文件直接失败，不会截断；大文件流式传输不在本改动范围内。浏览器策略和用户仍控制最终保存。

控制器测试覆盖字节不变、中文基本文件名、重复操作、失败、取消、迟到结果、URL 清理，以及等待完全停稳的释放。录制会话的浏览器场景在禁用 Office 转换时，对 Word、Excel、PDF、文本及不支持预览的文件逐字节比较下载结果，并验证匿名访问、超限文件和已删除文件均被拒绝。
