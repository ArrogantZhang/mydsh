# 家人小屋主题

[English](family-theme.md) | 中文

## 概述

使用家庭名称、欢迎语和温馨配色，同时保留 DSH 原有聊天控件。浏览器会保存这些外观选择。家庭封面上传到服务器，并与获准进入此实例的所有人共享。照片不会自动附加到任何会话。

<a id="enable-the-theme"></a>
## 启用主题

请先准备已构建的源码目录和现有 Web profile。按照可选[家庭组合包](../../../packages/bundle/family-theme/README.zh.md)中已验证的本地链接说明添加它，然后重启该 profile。该包尚未在公共 npm registry 提供。请保持现有邀请码和反向代理配置处于启用状态。

若另一个皮肤已占用品牌展示或自定义配色，请先明确停用该展示。家庭主题会报告冲突，不会悄悄覆盖它。

<a id="personal-appearance"></a>
## 个人外观

打开“设置 → 通用设置 → 布置小屋”。保存最多 16 个 Unicode 字符的名称、最多 32 个字符的欢迎语，并选择“暖阳清晨”“花园午后”或“炉火夜晚”。这些选择不会改变其他浏览器的外观。关闭“使用家庭主题”可恢复原界面。

使用建议卡片前，请先选择工作区。卡片只填写现有消息草稿；只有使用原有发送控件后才会发送。

<a id="shared-photos"></a>
## 共享照片

在首页或“布置小屋”中使用“上传家庭照片”。支持静态 JPG、PNG 和 WebP。服务器默认限制为 10 MiB、解码后 2400 万像素，处理后长边最多 1600 像素。服务器会清除拍摄信息，存储 WebP 而不是原文件。

每位已授权访问者都能替换或移除这一张共享照片。移除需要确认，并会为所有人恢复默认客厅插画。此功能没有相册、私有照片权限或个人所有者。

页面会在打开、重新获得焦点、重新连接或完成自身修改时刷新封面，不会持续推送照片更新。如果别人先修改了封面，请刷新并确认对方的图片后再重试；基于旧版本的修改不能覆盖它。

<a id="operations"></a>
## 运维

请把 `DSH_HOME/family-theme` 放在发布目录之外，并将其纳入备份。卸载或关闭主题会保留这些数据。服务必须继续使用经过鉴权的 `/api` 路由；不要为该目录添加公共静态路由。未登录的邀请码页面会采用家庭标题和本地配色，但绝不加载共享照片。

[存储参考](../../../packages/host/family-cover/README.zh.md)定义处理限制与失败语义。[外观参考](../../../packages/client/ui-family-theme/README.zh.md)定义浏览器持久化和冲突行为。部署仍需要现有的[邀请码鉴权配置](../../../deploy/alibaba-cloud/README.zh.md)。
